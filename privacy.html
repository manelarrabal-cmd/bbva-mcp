# Privacy Policy **Last updated:** September 24, 2026 This application, **BBVA Claude MCP**, is a personal project developed for private, non-commercial use. ## 1. Purpose The application is intended to allow the owner to access and analyse information from their own BBVA bank accounts through Enable Banking and, subsequently, a private MCP integration with Claude. ## 2. Personal data The application may process banking information belonging to the account owner, including account information, balances and transaction data. This information is used solely for the owner's personal financial analysis and automation. ## 3. Data sharing Banking information is not sold or shared with third parties for commercial purposes. Access to banking information is provided through Enable Banking's regulated open-banking infrastructure and the user's authorised banking connection. ## 4. Data storage The application is designed for personal use. Banking data will only be stored when necessary for the operation of the personal integration and will not be made publicly available. Authentication credentials, passwords and security codes are not stored by this application. ## 5. Security The application does not request or store the user's BBVA password or authentication codes. Authentication is performed directly through the bank's authorised authentication process. Private API credentials and cryptographic keys are kept confidential and are not published in the source code repository. ## 6. Contact This application is maintained by the owner of the GitHub repository associated with this project. For questions regarding this privacy policy, please contact the repository owner through GitHub. ## 7. Changes This privacy policy may be updated when the application or its data-processing practices change.
